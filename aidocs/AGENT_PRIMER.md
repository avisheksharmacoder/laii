# LAII Agent Primer: Core Rules & Quick Reference

This document is the **mandatory context primer** for all AI coding agents working on the Liquid AI (LAII) repository. Read this before designing changes, touching header files, or writing implementation code.

## 🧭 The 7 Golden Rules of LAII

### 1. Zero External Dependencies
* **Standard:** ISO C11 (`-std=c11`) and standard POSIX Linux interfaces only (`open`, `mmap`, `madvise`, `posix_fadvise`, `pthread`, `futex`).
* **Forbidden:** Never add external third-party dependencies (no OpenMP runtime `libgomp`, no BLAS, no PyTorch, no cURL, no JSON libraries).
* **Self-Contained:** Everything—including BPE tokenization, HTTP server, grammar masking, and thread pool—is implemented natively in zero-dependency C11.

### 2. Zero Dynamic Allocations in Autoregressive Forward Loops
* **Rule:** `malloc`, `calloc`, `realloc`, and `free` are strictly forbidden inside token decode loops ([`lfm_forward.c`](file:///home/avisheks/Documents/python-projects/Python-projects/laii/src/lfm_forward.c), [`lfm2_forward.c`](file:///home/avisheks/Documents/python-projects/Python-projects/laii/tools/lfm2_forward.c), [`lfm_engine.c`](file:///home/avisheks/Documents/python-projects/Python-projects/laii/src/lfm_engine.c)).
* **Pre-allocation:** All intermediate activation buffers, RoPE lookup tables, and scratch spaces must be preallocated inside the 64-byte aligned linear memory arena ([`arena.c`](file:///home/avisheks/Documents/python-projects/Python-projects/laii/src/arena.c)) or in persistent engine structs at startup.

### 3. Strict 64-Byte Alignment & `lfm2_aligned_alloc_64` Rule
* **Rule:** AVX2 SIMD instructions (`_mm256_load_ps`, `_mm256_store_ps`, `_mm256_load_si256`) require strict 32-byte or 64-byte aligned memory addresses. Misaligned access on aligned load instructions triggers immediate segmentation faults (`SIGSEGV`).
* **C11 `aligned_alloc` Constraint:** According to the C11 standard and AddressSanitizer, when calling `aligned_alloc(alignment, size)`, **`size` MUST be an integral multiple of `alignment`**!
* **Helper Pattern:** Always use `lfm2_aligned_alloc_64(size)`:
  ```c
  static inline void *lfm2_aligned_alloc_64(size_t size) {
      size_t aligned_size = (size + 63) & ~((size_t)63);
      return aligned_alloc(64, aligned_size);
  }
  ```

### 4. Recurrent ShortConv Invariance (Dual State Paradigm)
* **The Dual Nature:**
  * **GQA Layers:** State is stored in an append-only linear KV-cache. Rewinding or shifting simply adjusts index pointers.
  * **ShortConv Layers:** State is stored in a 2-token rolling buffer $(s_0, s_1)$ per channel ($2 \times D \times \text{sizeof(float)}$ bytes). Each token forward step mutates this buffer **destructively in-place**:
    $$s_0 \leftarrow s_1, \quad s_1 \leftarrow u_t$$
* **Implications for Agents:**
  * **Speculative Decoding / Tree Search:** You **cannot** simply rewind `pos <- pos - M` upon draft rejection. You must snapshot and restore recurrent states via [`LFM2Checkpoint`](file:///home/avisheks/Documents/python-projects/Python-projects/laii/tools/lfm2_moe_checkpoint.c#L350).
  * **Context Shifting (Attention-Sink):** When shifting context down, ShortConv layers require **0 memory movement or rotation** (they only hold $t-2, t-1$).
  * **Prompt Caching (`--prompt-cache`):** You **cannot** partially slice a 500-token cache to 300 tokens. The cache file stores ShortConv states at step 500. Caching requires a **100% bit-for-bit full prefix match** of all $N_{\text{cached}}$ tokens.

### 5. Multi-ISA Dynamic CPUID Dispatch
* **Rule:** Never hardcode AVX2/FMA/F16C instructions in such a way that crashes older CPUs with `SIGILL`.
* **Convention:** Decorate vector functions with target attributes:
  ```c
  __attribute__((target("avx2,fma,f16c")))
  void my_kernel_avx2(...) { ... }
  ```
  Provide portable scalar C11 fallbacks and bind function pointers at startup via CPUID inspection (`lfm2_init_cpu_kernels` in [`tools/lfm2_cpuid_quants.c`](file:///home/avisheks/Documents/python-projects/Python-projects/laii/tools/lfm2_cpuid_quants.c)). Support `LFM2_FORCE_ISA=scalar` for regression testing.

### 6. Mathematical Parity Before Optimization
* **Golden Reference:** All optimizations (batched prefill, 1x4 row unrolling, fused SwiGLU, planar ShortConv, online softmax) must produce numerical results that match scalar or PyTorch golden references within float tolerance ($< 10^{-5}$ relative diff, or exact bit-for-bit parity where appropriate).
* Reference tensors are generated by [`tools/generate_reference_tensors.py`](file:///home/avisheks/Documents/python-projects/Python-projects/laii/tools/generate_reference_tensors.py) and [`tools/create_toy_gguf.py`](file:///home/avisheks/Documents/python-projects/Python-projects/laii/tools/create_toy_gguf.py).

### 7. Absolute Sanitizer Cleanliness (`make test-asan`)
* **Standard:** Memory safety is verified via `-fsanitize=address,undefined -fno-omit-frame-pointer`.
* Any memory leak, out-of-bounds pointer arithmetic, misaligned cast, integer overflow, or undefined behavior aborts compilation or execution. Always run `make test-asan` before considering your task finished.

### 8. Public C11 ABI Decoupling & Pull-Based Streaming
* **Opaque Handles:** Public consumers (C, C++, Rust, Python) must interact exclusively via opaque handles (`lfm2_model_t`, `lfm2_context_t`, `lfm2_checkpoint_t`) defined in [`include/lfm2.h`](file:///home/avisheks/Documents/python-projects/Python-projects/laii/include/lfm2.h) and implemented in [`src/lfm2_api.c`](file:///home/avisheks/Documents/python-projects/Python-projects/laii/src/lfm2_api.c).
* **Zero Symbol Leaks:** Dynamic library `lib/liblfm2.so` is compiled with `-fvisibility=hidden`. Zero internal structs (`GGUFTensor`, `block_q8_K_t`, `LFM2ThreadPool`) or private engine functions may leak into the exported symbol table.
* **Pull-Based UTF-8 Generator:** Never implement blocking callback loops that require language wrappers to spawn background threads and `queue.Queue`. Use `lfm2_context_next_utf8()`, which internally steps forward passes until complete UTF-8 codepoints are assembled.
* **Zero-Copy Logits Access:** Read raw logit distributions directly via `lfm2_context_get_logits_ptr()`. This returns an $O(1)$ `const float*` to `ctx->state.logits` without heap allocations, enabling external sampling and parity testing.

### 9. Zero-Stall Cooperative Event Loop & `EPOLLRDHUP` Cancellation
* **Cooperative Stepping:** The non-blocking Linux `epoll` server ([`tools/lfm2_server.c`](file:///home/avisheks/Documents/python-projects/Python-projects/laii/tools/lfm2_server.c)) must never block inside a generation loop. It transitions active SSE clients to `CONN_STREAMING_SSE`, executes `lfm2_context_next_utf8()` **once per event loop tick** (~10–25 ms), dispatches with `MSG_NOSIGNAL` and `TCP_NODELAY`, and immediately returns to `epoll_wait(0)`.
* **Instant Client Disconnect:** Must catch `EPOLLRDHUP | EPOLLHUP | EPOLLERR` on token boundaries to immediately abort generation and free CPU cores when a browser user stops generation or cancels a `curl` stream.
* **Zero Heap Allocations:** Must pre-allocate fixed array `LFM2HttpConn conns[32]` with 64 KB request and 128 KB response buffers and scratch response memory—never allocate `malloc`/`free` during request handling.

## ⚡ Dual-Build Architecture Boundary

LAII maintains two parallel compilation paradigms:
1. **Core Library & Executables (`src/`, `include/`):**
   * Built via `make all` -> produces `lib/liblfm.so`, `lib/liblfm.a`, `lfm-run`, and `lfm-server`.
   * Standard header include path is `-Iinclude`.
   * Tensors use `dims[4]` for shape dimensions (from `include/gguf.h`).
2. **Standalone C11 Tools & Benchmarks (`tools/`):**
   * Self-contained single-file engines that compile with zero external headers (`tools/lfm2_*.c`).
   * Tensors use `ne[4]` for shape dimensions (from `tools/lfm2_loader.c`).
   * When sharing headers/code between `src/` and `tools/`, use conditional guards:
     ```c
     #if defined(LFM_GGUF_H) || defined(LFM_MODEL_H)
     /* Using core library types: tensor->dims */
     #else
     /* Using standalone tool types: tensor->ne */
     #endif
     ```
